# Screen drafts

First drafts of the app screens, 2026-10-23. Source files for the design canvas "Bridge Ride PDX screens" on claude.ai (private to Whitney until shared). The canvas is where they are viewed and edited; these copies are for version history.

Look: "Wayfinding", after bike and transit route signs. Barlow Semi Condensed for headings and signs, Inter for text. Colors: ink #15211D, ground #F3F5F2, greenway green #1B6B45, river blue #1F5F8B, signal orange #B4480F for warnings. Touch targets 44 px or larger.

| File | Screen | Rules shown |
|---|---|---|
| `Main.dc.html` | Map, idle: where you are, nearby bike routes, nearest bridges | L-01 to L-04 |
| `Plan.dc.html` | Plan a route: stops by type, style, Start ride (test ride 13) | T-01 to T-10, Y-01 |
| `Ride.dc.html` | Ride: next turn with lane side, GPS estimated state, lift warning | E-01, P-02, X-04 |
| `Bridge.dc.html` | Bridge sheet: category, which side, who shares it, description | B-14, C-09, D-07, E-02 |
| `Library.dc.html` | Saved routes and ride log | D-05 |
| `Settings.dc.html` | Defaults, overpass preference, battery check, privacy | T-04, T-05, O-02, N-07, D-02 |
| `Welcome.dc.html` | First launch: intro, Samsung battery steps, no permission yet | N-06, N-07 |
| `PCPlan.dc.html` | PC prototype plan page | prototype-spec.md |

Placeholders in square brackets ([time], [%], [date]) are values the app does not compute yet.
