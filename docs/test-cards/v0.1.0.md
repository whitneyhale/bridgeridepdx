Release: v0.1.0   Task: 1.3 (recorder)   Slice: S1

What changed: first Android build. Records a ride with the screen on or locked and exports a GPX. No map yet (task 1.2).

Install: open this release page in Chrome on the phone, tap the .apk, allow Chrome to install apps when asked. Or plug the phone into the PC and run `adb install -r bridgeride-v0.1.0.apk`.

One-time setup: open Bridge Ride, tap Open App info, Battery, Unrestricted. Make sure Bridge Ride is not on the Sleeping apps list.

Bike test (30 min):
1. Tap Start ride before you lock the phone. Allow precise location.
2. Ride 20 minutes with the screen on.
3. Lock the screen for 10 minutes and keep riding.
4. Unlock, hold the dark Stop button for 1 second.
5. Tap GPX on the ride and save it.

Pass when: the ride row says "no gaps over 10 s" for the screen-on part, and the GPX opens in gpx.studio with the track on the streets you rode. Gaps while locked are recorded, not failed: they answer whether locked riding works (N-06).

Questions:
1. Did the GPS line ever turn orange? Where?
2. Was hold-to-stop easy with gloves?
3. Was the screen readable on the bars (light or dark)?

Send back: pass or fail, the GPX, answers.
