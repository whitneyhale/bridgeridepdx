# Test Rides

Pass/fail checks for routing realism. "Home" is the rider's starting point and is kept out of the repo on purpose.

A ride passes when the route matches what the rider would actually ride: same bridge, same main streets, nothing unsafe. Record Pass or Fail, plus where it went wrong.
